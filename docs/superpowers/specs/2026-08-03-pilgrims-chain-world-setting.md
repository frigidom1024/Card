# 《巡礼者之链》世界观设定

**日期：** 2026-08-03  
**状态：** 概念设定初稿  
**用途：** 为卡链、棋盘事件、战斗、卡牌美术与章节内容提供统一的叙事语境。

## 1. 一句话世界观

神明已死，尸体化为破碎的“圣土棋盘”。玩家作为最后的“巡礼骑士”，以卡牌拼接朝圣之路，在神躯之上行走、回收神之遗骸，并决定是否让神明重归完整。

## 2. 故事前提

千年前，神明“穹主”在与“深渊”的战争中陨落。祂的躯体碎裂成无数悬浮于虚空的“圣土”：每一块圣土是一张 10×8 的棋盘，封印着祂的一段神性——力量、记忆、情感或祝福。

玩家是穹主陨落前亲吻过的最后一名骑士。那一吻令其获得不死的诅咒，亦是延续至今的祝福。骑士在破碎圣土间往返，唯一的使命是回收散落的神性碎片，将穹主的身体一块一块拼回完整。

## 3. 玩家身份与情感核心

玩家并非纯粹的救世者，而是未能替神明挡下深渊之刃的幸存者。每一次朝圣都是一次补偿：骑士踏上神明的遗体，触及祂仍未愈合的伤口，也被迫重新面对当年的失败。

> “我是神吻过的骑士，在祂破碎的尸体上行走。每一次朝圣，我都在触摸祂的伤——那些我当年没能替祂挡下的深渊之刃。”

## 4. 机制与叙事映射

| 游戏机制 | 叙事解释 |
| --- | --- |
| 卡链 | 朝圣之路。每放置一张卡，骑士便在神明的肉体上踏出一步；路径必须遵守圣链规则，虔诚、连续且不可回头。 |
| ROOT 起点 | 圣痕起点。神血滴落之处，是骑士感知到最近神性共鸣的位置。 |
| 10×8 棋盘 | 一块独立的圣土，是穹主遗体的一部分。 |
| MONSTER 事件 | 神之残响。神明死前的恐惧、痛苦、愤怒等情绪凝结而成的怪物。 |
| SHOP 事件 | 朝圣者营地。仍在圣土间流浪的巡礼者进行补给、交易与交换誓言。 |
| TREASURE 事件 | 神性碎片。玩家从记忆、力量或祝福中选择其一，决定本次朝圣带回何种残片。 |
| 链式战斗 | 圣礼对决。卡链是一套祈祷序列：根卡为起祷，其余卡牌依次吟诵，释放审判、庇护、治愈等圣光效果。 |
| 清空棋盘 | 圣礼完成。所有神性碎片被触及后，圣土获得净化并化作光芒收束。 |
| 局内失败与重启 | 不死诅咒使骑士不断重返朝圣起点，但每一次失败都留下新的伤痕与记忆。 |

## 5. 视觉锚点

### 卡牌

- 卡牌是一块石质“圣牌”或纹章，带有磨损、裂隙和镀金边缘。
- 卡面使用圣经细密画与油画笔触：骑士、圣徒、天使、荆棘冠、圣光与残缺肢体。
- 牌背为磨损羊皮纸纹路，暗示誓言被反复书写、撕毁与重订。

### 棋盘与场景

- 圣土以灰白大理石为基底，裂缝中流动金色神性纹路。
- 棋盘既是战略地图，也是放大的神躯组织；不同区域可暗示骨、血、皮肤、记忆或器官。
- 虚空、光尘与漂浮残骸构成场景背景，强调圣土的孤悬感。

### 角色与敌人

- 巡礼骑士穿着厚重铠甲和飘逸斗篷；金属反光采用厚涂油画质感。
- 神之残响保留人形或神性器官的轮廓，但由情绪、圣光残渣和深渊创伤扭曲而成。

## 6. 内容设计原则

每块圣土应有一处明确的“神之伤”，由一种神性、一个局内规则倾向和一组事件主题共同构成。例如：

- **遗忘之眼：** 与记忆相关；地图信息不完整、事件会改写路线或卡牌描述。
- **愤怒之右手：** 与力量相关；战斗压力更高，奖励偏向攻击与审判。
- **拒绝原谅的心脏：** 与情感相关；敌人会反映骑士的愧疚，奖励偏向治疗、护盾与和解。

这样，关卡主题不只是更换美术和敌人，而是让规则、奖励、事件与叙事共同呈现同一段神性创伤。

## 7. 主线悬念

“让穹主重归完整”不应从一开始就被确定为唯一正确答案。随着神性碎片回收，玩家应逐步发现：

- 深渊究竟是外敌，还是穹主自身的一部分；
- 神明复活会带来救赎，还是重启千年前的战争；
- 其他巡礼者为何仍在交易、阻拦或引导玩家；
- 骑士想复原神明，是出于信仰、责任，还是无法原谅自己。

结局可围绕“复原”“封存”“分赠神性”或“由骑士承受神性”展开，使卡牌选择与收集路径具备最终的道德与情感重量。

## 8. 设计基调

- **神圣而破碎：** 美不是洁净无瑕，而是经过战火、时间与悔恨后的庄严。
- **悲怆而克制：** 角色不以夸张哭喊表达痛苦，而以仪式、遗物与沉默显露伤口。
- **信仰存在代价：** 每一步朝圣既靠近神明，也可能把骑士带回最不愿回忆的过去。
