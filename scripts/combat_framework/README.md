# 新版战斗框架

本目录存放新的批次驱动战斗框架，与 `scripts/combatv2/` 中的旧版战斗系统物理隔离。

## 目录职责

- `protocol/`：效果、批次、事件、验证结果和战斗结果协议。
- `state/`：运行状态、只读快照、批次草稿和受控状态写入器。
- `batch/`：批次队列、效果处理器注册表和唯一状态提交处理器。
- `effects/`：标准效果类型、效果处理器和死亡等状态规则。
- `runtime/`：战斗时钟、驱动、流程提供器、触发规划器和顶层会话。

## 游戏层入口

游戏层优先通过 `runtime/combat_battle_session.gd` 中的 `CombatBattleSession` 组装和运行新战斗，不应直接修改 `CombatRuntimeState`。

当前框架尚未替换旧遭遇入口；正式切换前，两套系统应继续保持独立。
