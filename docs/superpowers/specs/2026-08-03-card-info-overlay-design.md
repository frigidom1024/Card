# MonoCard 卡牌独立悬浮信息面板设计

**日期：** 2026-08-03
**状态：** 已确认，待实施计划
**目标：** 左键悬停卡牌实体时，使用独立且始终正向的信息面板展示卡牌详情；卡牌旋转不影响阅读。

## 1. 背景与问题

当前 `CardInfo` 是 `CardEntity` 的子节点。牌链中的卡牌会根据方向旋转，子节点会继承该旋转，导致信息面板随实体倾斜或翻转，无法稳定阅读。

## 2. 已确认的交互

1. 信息面板在鼠标进入可交互的 `CardEntity` 时显示。
2. 鼠标离开卡牌实体时立即隐藏；面板本身不保持悬停状态。
3. 面板不接收鼠标事件，不改变拖拽、点击和现有的离开隐藏规则。
4. 面板靠近当前卡牌显示，优先位于卡牌右侧；右侧空间不足时自动置于左侧。
5. 面板保持屏幕正向，不继承卡牌的位置旋转或缩放变换。

## 3. 目标结构

```text
Gameplay UI
└─ CardInfoOverlay (CanvasLayer)
   └─ CardInfo (PanelContainer)

CardEntity (Area2D)
├─ CollisionShape2D
└─ CardView
```

- `CardInfoOverlay` 是全屏 `CanvasLayer`，位于玩法对象之外。
- `CardInfo` 从 `CardEntity` 场景移至该独立悬浮层，作为唯一复用的信息面板。
- `CardEntity` 保留卡牌数据、悬停和隐藏时机；它只向悬浮层发送显示或隐藏请求。

## 4. 定位规则

1. 使用卡面右缘的全局屏幕坐标作为首选锚点，额外保留固定间距。
2. 面板尺寸完成布局后，若其右缘超过可视区域，则改以卡面左缘为锚点显示在左侧。
3. 面板的上下位置钳制在视口安全边距内，避免内容被裁切。
4. 卡牌旋转只影响卡面的视觉和世界位置；面板不设置任何与卡牌相关的旋转。

## 5. 实施边界

本次覆盖：

- 新增或复用全屏 `CanvasLayer` 承载卡牌信息；
- 将 `CardInfo` 从 `CardEntity` 节点树中移除；
- 实现卡牌屏幕空间定位、左右翻边和纵向钳制；
- 保持当前卡牌详情字段、样式和悬停隐藏行为；
- 增加覆盖独立层级、屏幕空间定位、翻边和隐藏行为的自动化测试。

本次不覆盖：

- 固定侧边栏或鼠标跟随提示；
- 面板进入动画、固定选中或多卡牌对比；
- 卡牌详情内容与视觉主题重做；
- 移动端或触摸屏专用交互。

## 6. 验收标准

1. 任意旋转角度的卡牌悬停时，信息面板文字始终水平可读。
2. 面板不再是卡牌实体的子节点，且不随其旋转。
3. 普通位置的卡牌优先在右侧显示信息；靠近右边缘时信息面板显示在左侧。
4. 面板不会超出当前视口的上下边界。
5. 鼠标离开卡牌后面板立即隐藏，鼠标移入面板不会延长显示时间。
6. 现有卡牌点击、拖拽、放大查看和展示模式不受影响。
