# 《PILGRIM'S CHAIN》主页视觉优化设计

- **日期：** 2026-08-03
- **状态：** 待用户审阅
- **范围：** 主菜单页面的标题层级、背景可读性、主按钮视觉状态与底部信息。

## 1. 目标

保留现有油画背景作为世界观主视觉，将主菜单从“文字覆盖在插画上”调整为可读、克制、具有书封与旅途遗物气质的入口页。

页面必须在第一眼依次传达：游戏名、卡牌牌链定位、唯一主操作。首版不以避让背景插画为布局约束；UI 优先采用清晰、常规、便于未来扩展多个菜单操作的居中层级。

## 2. 视觉基调

全局使用“暗蓝书封 + 金箔封印”语言：

- 基础色为墨蓝近黑、焦黑棕、骨白、旧金；不使用当前偏鲜的绿色按钮。
- 材质表现为哑光旧书封、压花金属边、低强度金箔高光；不使用现代玻璃、霓虹或大面积圆角。
- 标题是古金金箔；副标题是低饱和羊皮纸金；正文与交互文字保持高可读性。

## 3. 页面层级与布局

```text
背景插画（原图）
└── SafeArea（全屏统一留白）
    ├── 顶部 12–28%：游戏标题与副标题
    ├── 视觉中心 46–58%：菜单操作组
    │   └── 主按钮「踏上巡礼」
    └── 底部：低对比度版本号
```

1. `GameLogo` 保持顶部水平居中，字号收敛到约 `118–124px`，但不为了避让背景元素改变其标准标题位置。
2. `GameSubtitle` 缩小至 `22–28px`，加宽字距，保持在标题下方；它只负责说明，不与标题竞争。
3. 增加轻微的全屏暗角和顶部黑蓝渐隐，使所有 UI 可读；该遮罩不承担为插画留白的职责。
4. `ActionBlock` 固定在视窗垂直 `52%` 左右，是标准居中的菜单操作区；未来新增“继续游戏”“设置”等选项时，在主按钮下以 `12–16px` 间距纵向扩展。
5. 主按钮文字改为 `踏上巡礼`；首版不显示键盘提示，避免在只有一个操作时制造冗余信息。
6. `ActionBlock` 内新增 `ActionPanel`：它是主按钮区域的半透明墨蓝书封面板，负责从复杂背景中稳定分离交互内容；标题和版本号不放入此面板。

## 4. 主按钮规格

按钮继续使用 Godot `Button`，以主题 `StyleBox` 表现，不要求新增图片资源。

| 属性 | 规则 |
|---|---|
| 尺寸 | 约 `300–320 × 68–72px` |
| 形状 | `6px` 以下的小圆角或切角；避免当前大圆角 |
| Normal | 墨蓝近黑哑光底、暗金外边与亮金内边、骨白文字 |
| Hover | 金边及文字提亮，阴影扩散，按钮视觉上浮 `2px` |
| Pressed | 背景压暗、内阴影加强、内容下沉 `2px` |
| Disabled | 灰蓝底、暗铜边、去除高光，文字降低对比度 |
| Focus | 额外细金色描边，确保键盘导航可见 |

按钮状态差异应明确但克制：Hover 是“被烛火照亮”，Pressed 是“按入旧书封”，Disabled 是“金箔褪尽”。

### ActionPanel 规格

`ActionPanel` 使用 `PanelContainer` 与 `StyleBoxFlat` 实现，不需要新增图片资源。

| 属性 | 规则 |
|---|---|
| 尺寸 | 初始约 `430 × 150px`，可随菜单项增多向下扩展 |
| 背景 | 深墨蓝近黑，透明度 `45–55%`；保留背景插画的微弱可见性 |
| 边框 | `1px` 暗金细线与极弱内侧金色高光，不使用厚重描边 |
| 阴影 | 柔和黑色投影；不使用玻璃拟态、强模糊或霓虹发光 |
| 内边距 | 水平 `32px`、垂直 `26px`，使按钮不贴近边缘 |

面板的视觉权重必须低于按钮：它像旧书封的暗色内页，只承担承托作用，不与唯一 CTA 争夺注意力。

## 5. 非目标

- 不替换现有主页背景，不新增 Logo 位图，不新增主菜单功能按钮。
- 不改变 `开始游戏 → 牌根选择 → 开始探索` 路由、信号或调试启动逻辑。
- 不在本次引入音效、粒子、循环动画或新的主题系统资源；这些待基础布局验证后另行设计。

## 6. 验收标准

1. 在 `1920×1080` 下，标题位于顶部、主按钮位于视觉中心，层级清晰且不因背景图局部构图改变。
2. 主按钮不再使用绿色，四种交互状态在鼠标与键盘导航下都可区分。
3. `踏上巡礼` 是唯一主操作，点击仍只发射一次 `start_game_requested` 并禁用按钮。
4. `ActionPanel` 在 `1920×1080` 下保持半透明、暗金细边与清晰内边距，按钮仍是面板内的唯一视觉焦点。
5. 现有主页流程和自动化测试继续通过；新增测试覆盖按钮文字、面板节点、禁用样式与焦点样式的资源存在。
