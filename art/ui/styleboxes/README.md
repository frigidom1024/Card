# Pixel panel 9-slice

`panel_white_pixel_9slice.png` is generated by `tools/generate_pixel_panel.py`.

## Godot StyleBoxTexture setup

1. Assign this texture to a new **StyleBoxTexture**.
2. Set **Texture Margin Left / Top / Right / Bottom** to `8`.
3. Set both axis stretch modes to **Stretch** (the centre is solid white).
4. In the texture import options, set **Filter** to `Nearest` and disable **Mipmaps**.

The generated texture is 32×32 px. It contains a 2 px ink outline, white fill,
stair-stepped pixel corners, and a 4 px hard shadow extending to the right and bottom.
