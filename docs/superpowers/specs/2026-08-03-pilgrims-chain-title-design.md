# 《巡礼者之链》主菜单标题设计

**日期：** 2026-08-03  
**状态：** 已确认，待实施（内置字体金箔方案）  
**目标：** 将主菜单顶部标题从旧森林主题切换为《巡礼者之链》的神圣、破碎与暗金石质视觉语言，同时明确卡链玩法。

## 1. 已确认文案

```text
PILGRIM'S CHAIN
A CARD-CHAIN PILGRIMAGE
```

- 主标题承担世界观、情绪与品牌识别。
- 副标题明确这是围绕卡牌接链展开的朝圣游戏。
- 不在标题区保留 `MONOCARD` 或“在蔓生森林中编织你的牌链”。

## 2. 视觉规格

### 主标题

- 使用现有 `GameLogo` Label 与 Godot 内置字体；不新增字体文件、图片资源或场景节点。
- 文案：`PILGRIM'S CHAIN`。
- 保持字号 90 与横向居中，利用加粗轮廓和层次投影模拟中世纪金箔艺术字。
- 正文字色改为明亮古金色，使用近黑棕描边以保证背景上的字形边界。
- 投影使用琥珀暗金并向下偏移，营造鎏金压印与轻微石刻深度；不使用森林亮绿或强烈霓虹发光。

### 副标题

- 使用现有 `GameSubtitle` Label。
- 文案：`A CARD-CHAIN PILGRIMAGE`。
- 使用全大写、小字号、居中排列。
- 使用比主标题更低饱和的羊皮纸金色，并添加极细深色描边，确保层级分明且在背景图上可读。

## 3. 实施边界

本次覆盖：

- 修改 `scenes/home/main_menu_screen.tscn` 中的两个标题 Label 文案和主题覆盖样式；
- 更新主菜单流程测试，验证新主标题与副标题均存在；
- 通过 Godot headless 测试与编辑器资源加载检查验证场景。

本次不覆盖：

- 背景图、按钮、版本号、菜单布局或交互逻辑；
- 新字体文件、Logo 位图、动画或音效；
- 其他菜单和游戏内 UI 的主题迁移。

## 4. 验收标准

1. 主菜单显示 `PILGRIM'S CHAIN` 与 `A CARD-CHAIN PILGRIMAGE`。
2. 主标题呈现明亮古金、近黑棕描边和琥珀暗金投影的金箔艺术字效果；副标题保持低饱和羊皮纸金色。
3. 标题在现有背景图上保持居中且可读。
4. 现有“开始游戏”按钮、焦点行为和 `start_game_requested` 信号保持不变。
